## Клиент и сервер

```mermaid
sequenceDiagram
    participant C as Клиент (наш CLI)
    participant S as Сервер (instruments-service)
    C ->> S: запрос по сети
    Note over S: обрабатывает запрос
    S -->> C: ответ по сети
```

| Сегодня                                                        | Потом                                     |
|----------------------------------------------------------------|-------------------------------------------|
| Пишем **клиентов** (`HttpClient`, затем Feign/OkHttp на выбор) | Пишем **сервер**                          |
| Моковый сервер — готовая чужая реализация                      | `instruments-service` разбирается изнутри |

## HTTP: запрос и ответ

```mermaid
flowchart LR
    subgraph Request["Запрос"]
        direction TB
        RM["GET /v1/instruments HTTP/1.1"]
        RH["Headers: Accept, ..."]
        RB["Body (может быть пустым)"]
    end

    subgraph Response["Ответ"]
        direction TB
        SM["200 OK"]
        SH["Headers: Content-Type, ..."]
        SB["Body: JSON"]
    end

    Request -->|по сети| Response
```

| Часть         | Запрос                   | Ответ                |
|---------------|--------------------------|----------------------|
| Статус-строка | метод + путь             | код ответа           |
| Заголовки     | формат тела, авторизация | `Content-Type` и др. |
| Тело          | обычно пусто (`GET`)     | JSON                 |

## Как это видно в Java: `HttpClient`

```java
void example() {
    HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(baseUrl + "/v1/instruments"))
            .header("Accept", "application/json")
            .GET()
            .build();

    HttpResponse<String> response = httpClient.send(request, HttpResponse.BodyHandlers.ofString());
}
```

Полная реализация — `HttpClientTInvestApiClient.java`, разбирается на этапе 2.
